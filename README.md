### ③チェックボックス  
チェックボックスをいれたいときは順序なしリストの記述の後ろに `[ ]` を入れるとチェックボックスが生成されます。  
チェックが入った状態のボックスを生成する場合は `[x]` を入力します。

- [ ] 花火行きたくない  
- [x] 花火行きたい
